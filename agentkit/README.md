# Agentkit

Pasta de organização para as operações realizadas em conjunto com o agente no
projeto `caixa-er`.

## Organização sugerida

- `context/`: contexto técnico e regras específicas do projeto.
- `tasks/`: tarefas, planos e registros de execução.
- `decisions/`: decisões de arquitetura e produto.

Os arquivos devem ser adicionados conforme forem necessários, evitando duplicar
informações que já pertencem à documentação principal do projeto.
